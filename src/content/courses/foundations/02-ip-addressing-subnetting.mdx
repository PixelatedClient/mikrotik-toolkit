## IPv4 basics

An IPv4 address is 32 bits, written as four decimal octets: `192.168.1.1`. Part of it identifies the **network**, the rest identifies the **host**.

## CIDR notation

`192.168.1.0/24` means the first 24 bits are the network part. The remaining 8 bits give 2^8 = 256 addresses.

| Prefix | Mask | Addresses | Usable hosts |
|---|---|---|---|
| /24 | 255.255.255.0 | 256 | 254 |
| /25 | 255.255.255.128 | 128 | 126 |
| /26 | 255.255.255.192 | 64 | 62 |
| /30 | 255.255.255.252 | 4 | 2 |
| /31 | 255.255.255.254 | 2 | 2 (point-to-point, RFC 3021) |

Usable hosts = total − 2 (network and broadcast addresses), except /31 and /32.

## Subnetting without a calculator

1. Find the **block size**: 256 − last non-255 mask octet. For /26 (mask .192) the block size is 64.
2. Subnets start at multiples of the block size: .0, .64, .128, .192.
3. Broadcast = next subnet start − 1.

Example: `192.168.1.100/26` is in block .64, so network `.64`, broadcast `.127`, hosts `.65`-`.126`.

## IPv6 in one minute

An IPv6 address is 128 bits, written in hex, e.g. `2001:db8::1` — RFC 4291 defines it as "a 128-bit identifier for interfaces and sets of interfaces." A global unicast address normally reserves the last 64 bits for the interface identifier, which is why a LAN subnet is almost always handed a /64. There is no broadcast address in IPv6 at all — RFC 4291 states its function "is superseded by multicast addresses" — so there is no NAT-driven address scarcity the way there is in IPv4.
